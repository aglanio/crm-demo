# CRM Demo

Protótipo de CRM single-page para gestão de leads, atendimento multicanal (WhatsApp, e-mail, SMS, voz IA) e automação de funil — voltado ao nicho de eventos.

100% front-end estático (HTML + Tailwind via CDN + Chart.js). Sem backend, sem build, sem dependências. Todos os dados são mock para demonstração.

## Rodar local

```bash
# qualquer servidor estático, ex:
python -m http.server 8000
# abre http://localhost:8000
```

Ou apenas abra `index.html` no navegador.

## Stack

- HTML estático
- [Tailwind CSS](https://tailwindcss.com) (CDN)
- [Chart.js](https://www.chartjs.org) (CDN)
